# Studio Vidéo 0.12.0 — Analytiques (début de la V4)

- Nouvel espace **Analytiques** : vidéos publiées comparées par concept, par plateforme, par compte et par vidéo
  (vues avec barres de comparaison, j'aime, commentaires, partages, taux d'engagement)
- **Relever les statistiques YouTube** : chiffres publics lus par l'API, y compris pour les vidéos publiées à la main
  (le lien suffit) — il faut un compte YouTube connecté
- **Saisir des chiffres** pour TikTok, Instagram, Facebook, X : recopiés depuis la plateforme, marqués « saisi »
- Un chiffre non fourni s'affiche « — », jamais 0 ; chaque relevé est daté et conservé (historique)
