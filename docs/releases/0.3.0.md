# Studio Vidéo 0.3.0 — Transcription et sous-titres

La V1 est complète.

- Transcription automatique sur votre PC, sans envoi en ligne (faster-whisper)
- Modèles à télécharger une fois dans Paramètres → Matériel et moteurs (« small » recommandé)
- Correction du texte et des intervenants ; le texte original reste conservé
- Recherche dans la transcription ; un clic sur une phrase place la lecture au bon endroit
- Sélection de phrases → clip ou extrait de timeline
- Export TXT, SRT, VTT, JSON, ASS ; import de sous-titres existants
- Sous-titres générés automatiquement sur le montage, découpage réglable
- Mot prononcé surligné, apparition mot par mot, effet pop, fondu
- Police, couleurs, contour, ombre, fond, position ; zones TikTok / Reels
- Sous-titres incrustés et/ou fichier .srt séparé
- Style des sous-titres mémorisé par concept
