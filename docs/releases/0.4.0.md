# Studio Vidéo 0.4.0 — Clipping intelligent

Début de la V2 : trouver automatiquement les meilleurs passages d'une vidéo longue.

- Nouvel onglet « Moments forts » dans le Studio (parcours « Clipping intelligent » activé)
- Filtres : humour, débat et désaccord, politique, émotion, pédagogie, potentiel d'intérêt
- Mots-clés ou demande libre, intervenants à privilégier, nombre et durées des extraits, intensité
- Chaque proposition : score d'estimation, justification, accroche proposée, intervenants
- Protection du contexte : phrase coupée, réserve supprimée (« mais… »), réponse ou question coupée,
  chiffres à vérifier
- Lire, accepter, rejeter, favori, ajuster début et fin ; créer les clips ou les envoyer sur la timeline
- Analyse locale hors ligne ; modèle de langage facultatif (Ollama sur votre PC ou API de votre choix)
- Montage par le texte : décochez des phrases de la transcription pour obtenir la coupe
- Base de données mise à jour automatiquement (sauvegarde faite avant)
