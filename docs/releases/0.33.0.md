# Studio Vidéo 0.33.0 — Calendrier et concepts partagés entre ordinateurs, transcription plus pratique

## Le même calendrier sur plusieurs ordinateurs
- Dans **Paramètres → Général**, une nouvelle carte : **Calendrier et concepts partagés**.
- Créez un dossier dans OneDrive, Google Drive (avec l'application « Google Drive pour ordinateur ») ou Dropbox, puis
  choisissez **ce même dossier** sur chaque ordinateur avec « Choisir le dossier… ».
- Sont partagés :
  - le calendrier : date et heure, texte, logos cochés, liens des vidéos publiées ;
  - les concepts : nom, thématique, couleur, langue ;
  - les chaînes des concepts (YouTube, TikTok, Facebook ou Instagram) et leur adresse publique.
  Un ajout, une modification ou une suppression sur un ordinateur arrive sur les autres.
- Le dossier est relu toutes les 2 minutes. **Synchroniser maintenant** le fait tout de suite, et la date de la
  dernière synchronisation s'affiche dessous.
- Restent sur chaque ordinateur : les vidéos, les médias, les connexions par API et les brouillons. Une publication
  prévue sur un autre ordinateur affiche le nom de sa vidéo, suivi de « (sur un autre ordinateur) ».
- La première fois, un concept qui porte le même nom sur deux ordinateurs devient un seul concept.
- Une vidéo publiée que deux ordinateurs retrouvent chacun de leur côté n'apparaît qu'une fois au calendrier.

## Transcription
- La transcription s'ouvre dans un **rectangle volant**, sous le bouton « Transcription », et non plus dans une
  fenêtre.
- Plus de titre ni de bouton « Fermer » : un clic à côté ou la touche Échap la referme, et les corrections sont
  enregistrées.
- En haut, de gauche à droite :
  - une **barre de recherche** : seules les phrases qui contiennent le mot restent affichées, avec leur nombre à côté
    (majuscules et accents ignorés) ;
  - **Transcrire à nouveau** ;
  - l'historique ;
  - la roue crantée.
- La correction d'une traduction (drapeau dans l'onglet Traduction) s'ouvre de la même façon, près du drapeau.
