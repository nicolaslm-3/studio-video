# Studio Vidéo 0.9.0 — Intervenants et masquage de zones

- Transcription → Plus ▾ → « Identifier les intervenants… » : qui parle, phrase par phrase, calculé sur votre PC
  (nombre automatique ou imposé). Les noms « Intervenant 1, 2… » se renomment d'un double-clic et sont reportés
  sur les traductions ; l'original reste disponible
- Modèle d'empreintes vocales à télécharger une fois (26 Mo) : Paramètres → Matériel et moteurs → Modèles
- Limite connue : deux voix très proches peuvent être réunies en mode automatique ; imposez alors le nombre
  d'intervenants
- Cadrage → « Masquer une zone » : sous-titres incrustés ou logo d'origine, par flou, effacement ou bande noire.
  Zone réglable en %, plusieurs zones possibles ; visible dans l'aperçu fidèle et l'export
- Pas encore de détection automatique du texte incrusté (prévue)
