# Studio Vidéo 0.7.0 — Doublage

- Doubler une traduction : onglet Transcription → afficher la traduction → Plus ▾ → « Doubler cette traduction (voix) »
- Une voix par intervenant, choisie dans votre compte ElevenLabs (clé dans Paramètres → Matériel et moteurs) ;
  Piper (hors ligne) est proposé s'il est installé
- Chaque phrase est calée sur le temps de la phrase d'origine (accélération limitée à ×1,35) ;
  les phrases accélérées (⏩) ou en échec (⚠) sont signalées et peuvent être reprises une par une
- Montage → onglet Audio → Voix : « Doublage : anglais » ; voix d'origine remplacée ou gardée en fond
- Production en série : les variantes traduites prennent la voix doublée quand elle existe
- Confirmation obligatoire des droits sur les voix utilisées (voix clonée : accord de la personne)
- Limite connue : l'aperçu en direct joue la voix d'origine ; l'export utilise bien le doublage
