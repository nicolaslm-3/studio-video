# Studio Vidéo 0.11.0 — Mise en ligne automatique sur YouTube

- Paramètres → Concepts et comptes : renseignez l'identifiant de votre projet Google (guide : docs/YOUTUBE.md),
  sélectionnez le compte YouTube → **Connecter** (autorisation dans le navigateur). Le jeton est rangé dans le
  coffre d'identifiants Windows
- Publication → Actions ▾ → **Mettre en ligne sur YouTube** : immédiat, ou programmé chez YouTube à l'heure prévue
  (la vidéo part tout de suite, YouTube la publie seul : le PC peut être éteint)
- Option : à l'heure prévue, les publications des comptes connectés sont envoyées automatiquement (logiciel ouvert)
- Envoi par blocs, reprise automatique après coupure ; une vidéo déjà envoyée n'est jamais renvoyée
- Statut « Publiée » uniquement avec l'identifiant renvoyé par YouTube ; si YouTube laisse la vidéo privée,
  c'est signalé
- Les autres plateformes restent en publication assistée
