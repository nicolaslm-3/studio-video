# Studio Vidéo 0.6.0 — Traduction

- Traduire une transcription dans une ou plusieurs des 13 langues prioritaires
  (onglet Transcription → Plus → Traduire…)
- Moteurs : votre modèle de langage (hors ligne avec Ollama), DeepL ou Google Cloud Translation
  (clés à saisir dans Paramètres → Matériel et moteurs)
- Glossaire : noms et marques conservés tels quels (le nom du concept et les intervenants sont proposés)
- Chaque traduction est consultable et corrigeable, l'original reste intact
- Sous-titres dans la langue de votre choix (onglet Sous-titres → Langue → Générer)
- Production en série multilingue : un export par clip, par format et par langue
- Un fichier source introuvable n'ouvre plus de fenêtre bloquante
