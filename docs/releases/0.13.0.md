# Studio Vidéo 0.13.0 — Détection du texte incrusté

- Cadrage → Masquer une zone → **Détecter le texte incrusté et les logos** : l'extrait est analysé (≈ 30 images)
  et des zones sont proposées — logo ou filigrane fixe près d'un bord, sous-titres incrustés en bas de l'image
- Les zones sont ajoutées en flou ; changez la méthode (effacement, bande noire) ou ajustez-les, puis
  vérifiez avec « Aperçu fidèle » avant d'exporter
- La détection repère la présence de texte, elle ne le lit pas
