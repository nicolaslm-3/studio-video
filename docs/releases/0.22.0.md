# Studio Vidéo 0.22.0 — Archive de projet

- Studio → **Exporter le projet…** : une archive `.studioproj` avec le montage, les clips, les transcriptions
  corrigées, les traductions et les doublages ; les vidéos et sons inclus si vous le souhaitez
- Tableau de bord → **Importer un projet…** : sur un autre ordinateur, le projet est recréé à l'identique ; un média
  déjà présent dans la bibliothèque est reconnu (pas de copie en double), les autres sont extraits dans
  Vidéos\Studio Vidéo\Projets importés ; les médias absents sont signalés
- YouTube : un envoi interrompu (logiciel fermé) reprend là où il s'était arrêté, sans créer de doublon
