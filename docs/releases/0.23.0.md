# Studio Vidéo 0.23.0 — Retrait des silences, médias retrouvés, chapitres

- Studio → **Retirer les silences…** : les blancs d'une prise de parole sont coupés (analyse du son réel, ou des
  mots si le média est transcrit), avec une petite marge pour garder des coupes naturelles ; les sous-titres
  suivent et l'opération s'annule d'un clic
- Bibliothèque → **Retrouver le fichier…** pour un média déplacé ou renommé : l'empreinte vérifie que c'est bien
  le même fichier ; **Chercher dans un dossier…** retrouve d'un coup tous les médias introuvables
- Publication → **Proposer le texte** ajoute des **chapitres** à la description YouTube pour les vidéos de plus
  de 2 minutes (découpe aux pauses et mots-clés, ou par le modèle de langage s'il est configuré) ; YouTube
  les affiche automatiquement dans la barre de lecture
