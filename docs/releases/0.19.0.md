# Studio Vidéo 0.19.0 — Recadrage intelligent, Instagram, Facebook et X

- **Recadrage intelligent** (Cadrage → « Suivre les visages ») : d'une vidéo horizontale vers le vertical ou le carré,
  le cadre suit le visage principal ; il reste fixe quand la personne bouge peu, glisse en douceur sinon, et coupe
  net aux changements de plan. Visible dans l'aperçu et l'export ; option dans la Production en série
- **Instagram** (Reels d'un compte professionnel), **Facebook** (Reels d'une Page) et **X** : connexion des comptes,
  publication automatique (immédiate, ou à l'heure prévue si le logiciel est ouvert) et statistiques
  (guides : docs/META.md, docs/X.md)
- Détection du texte incrusté plus fiable sur les logos peu contrastés
- Inclut aussi la 0.16 à la 0.18 (Traduction guidée, Campagne, Création originale, voix hors ligne, TikTok), dont
  la publication sur GitHub avait échoué
