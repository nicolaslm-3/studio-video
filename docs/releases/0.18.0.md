# Studio Vidéo 0.18.0 — Publication automatique sur TikTok

- Nouvel onglet **Paramètres → Publication** : réglages YouTube et TikTok réunis (guide : docs/TIKTOK.md)
- **Connecter** un compte TikTok (autorisation dans le navigateur), puis dans une publication :
  Actions ▾ → **Publier sur TikTok maintenant**
- Une publication TikTok programmée part automatiquement à l'heure prévue si le logiciel est ouvert
  (l'API TikTok ne permet pas de programmer à l'avance)
- Envoi par blocs avec nouvelles tentatives, suivi du traitement par TikTok ; « Publiée » seulement quand
  TikTok renvoie l'identifiant public de la vidéo
- Application TikTok non encore auditée : la vidéo est publiée en privé et c'est signalé
- Analytiques : statistiques TikTok (vues, j'aime, commentaires, partages) relevées automatiquement
