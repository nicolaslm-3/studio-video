# Studio Vidéo 0.30.0 — Atelier de publication, historique des versions, voix doublée qui s'entend

## Publier sans API
- **Atelier de publication** : pour les comptes sans connexion par API (TikTok, Instagram, Facebook…), le logiciel
  prépare tout et vous laissez le dernier clic « Publier ». Le texte est copié d'office, la page d'envoi s'ouvre dans
  le navigateur du compte, et la vidéo se glisse directement depuis l'Atelier vers la page.
  Il s'ouvre tout seul après « Publier maintenant », et depuis le Calendrier.
- **Un navigateur par compte** : « Se connecter à ce compte » ouvre Edge avec un profil réservé à ce compte.
  Vous vous connectez vous-même, une fois ; le compte reste connecté, sans changer de session. Le logiciel ne voit
  jamais votre mot de passe.
- **Lien retrouvé tout seul** : une fois la vidéo en ligne, son lien est cherché sur la page publique du compte
  (YouTube et TikTok), au démarrage puis toutes les heures. Une correspondance sûre est confirmée d'elle-même. Un doute
  vous est proposé : « Est-ce cette vidéo ? ». Pour Instagram et Facebook, il faut encore coller le lien.
  Renseignez l'adresse publique du compte pour en profiter.
- La connexion par API reste possible, repliée dans « Avancé : connexion par API ».

## Le reste
- **Transcription** en haut de l'écran : lire et corriger la transcription, enregistrée au fil de la frappe.
  Elle peut aussi être faite par ElevenLabs Scribe v2.
- **Historique** des transcriptions, traductions et voix : chaque nouvelle version s'applique, et on peut revenir à
  une ancienne.
- **Traduction** : bouton « Traduire » et traduction corrigeable langue par langue ; doublage ElevenLabs à partir du
  son de la vidéo ; écoute d'un exemple de chaque voix ; régénérations illimitées.
- **La voix doublée s'entend** dès qu'on appuie sur lecture dans une version traduite.
- Le logiciel s'ouvre directement dans Montage libre. Il suit l'heure de votre PC. Les drapeaux s'affichent
  partout, y compris dans les textes de la vidéo.
- Fenêtre Médias flottante. Liste des tâches plus lisible : projet, étape et modèle, état en emoji.
- Vos projets et médias sont conservés lors de la mise à jour (sauvegarde automatique avant).
