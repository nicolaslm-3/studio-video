# Studio Vidéo 0.14.0 — Doublage audible dans l'aperçu

- La lecture du montage fait maintenant entendre ce que l'export produira :
  - « Voix : doublage » : la voix doublée, avec la voix d'origine au niveau choisi (coupée, ou en fond) ;
  - fond « musique et ambiance d'origine » : doublage + piste séparée ;
  - « Isoler la voix d'origine » : la voix seule.
- Les pistes restent calées sur la vidéo (recalage automatique au-delà de 120 ms d'écart)
