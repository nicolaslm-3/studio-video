# Studio Vidéo 0.21.0 — Texte de publication proposé, lecture fluide

- Publication → **Proposer le texte** : titre, description et hashtags rédigés à partir de ce qui est dit dans la
  vidéo (seulement les passages montés). Avec un modèle de langage : rédaction soignée, sans fait inventé ; sans :
  première phrase forte et mots-clés les plus fréquents. Toujours à relire
- **Aperçus légers** : les vidéos 4K, HEVC, ProRes… reçoivent automatiquement une copie 540p pour une lecture
  fluide dans le logiciel ; l'export utilise toujours l'original (Paramètres → Général pour désactiver)
